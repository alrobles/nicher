# Samples of environmental data from M hypothesis to estimate negative log likelihood from Abeillia abeillei presence points. This is a hummingbird example. A dataset with two variables containing points contains 2 bioclimatic variables

Samples of environmental data from M hypothesis to estimate negative log
likelihood from Abeillia abeillei presence points. This is a hummingbird
example. A dataset with two variables containing points contains 2
bioclimatic variables

## Usage

``` r
example_env_m_2d
```

## Format

A data frame with 10000 rows and 2 variables:

- bio1WH:

  temperature, in C

- bio12WH:

  precipitation, in mm
