# Species occurrence points to estimate negative log likelihood from Abeillia abeillei presence points. This is a hummingbird example. A dataset with three variables containing points contains 3 bioclimatic variables

Species occurrence points to estimate negative log likelihood from
Abeillia abeillei presence points. This is a hummingbird example. A
dataset with three variables containing points contains 3 bioclimatic
variables

## Usage

``` r
example_env_occ_3d
```

## Format

A data frame with 73 rows and 3 variables:

- bio1WH:

  temperature, in C

- bio12WH:

  precipitation, in mm

- bio19WH:

  Precipitation of Coldest Quarter, in mm
