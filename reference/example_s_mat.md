# Example of a covariance matrix of an ellipsoid from two environmental variables. The 2 x 2 matrix corresponded to a positive semi-definite matrix. In two dimensions encodes the rotation (orientation) and scaling of an ellipse.

Example of a covariance matrix of an ellipsoid from two environmental
variables. The 2 x 2 matrix corresponded to a positive semi-definite
matrix. In two dimensions encodes the rotation (orientation) and scaling
of an ellipse.

## Usage

``` r
example_s_mat
```

## Format

An object of class `matrix` (inherits from `array`) with 2 rows and 2
columns.

## Source

\<doi:10.1016/j.ecolmodel.2021.109823\>

## Examples

``` r
print(example_s_mat)
#>             bio1WH     bio12WH
#> bio1WH    7.977662    406.9154
#> bio12WH 406.915434 458467.6979
```
